4. Crear Model Producto
    4.1 Crear el modelo de producto:
        - php artisan make:model Producto -> Que crea app/Models/Producto.php
        - En app/Models/Producto.php:
            namespace App\Models;

            use Illuminate\Database\Eloquent\Model;

            class Producto extends Model
            {
                protected $table = 'productos';

                protected $fillable = [ //Aquí tienen que coincidir los nombres con los campos de las tablas creadas
                    'idProducto',
                    'nombreProducto',
                    'precio',
                    'imagen',
                    'destacado'
                ];
            }
    4.2 Crear el controlador por cargar los productos:
        - php artisan make:controller ProductoController -> Que crea app/Http/Controllers/ProductoController.php
        - En app/Http/Controllers/ProductoController.php:
            namespace App\Http\Controllers;

            use App\Models\Producto;

            class ProductoController extends Controller
            {
                public function index() //Esta funcion solo muestra los productos destacados
                {
                    $productos = Producto::where('destacado', 1)->get();

                    return view('index', compact('productos'));
                }
            }
            Esto hace SELECT * FROM productos
    4.3 Crear la ruta en routes/web.php:
        use App\Http\Controllers\ProductoController;

        Route::get('/', [ProductoController::class, 'index']);
    
    4.4 Mostrar los productos en la vista, en este caso resources/views/index.blade.php
        Se reemplazan las imágenes estáticas por:

        @foreach($productos as $producto)

        <div class="bg-white shadow rounded-lg overflow-hidden">

        <img 
        src="{{ asset('storage/'.$producto->imagen) }}" 
        alt="{{ $producto->nombre }}"
        class="w-full h-64 object-cover"
        >

        <div class="p-4">

        <h3 class="text-lg font-semibold">
        {{ $producto->nombre }}
        </h3>

        <p class="text-gray-600 mt-2">
        {{ $producto->precio }} €
        </p>

        </div>

        </div>

        @endforeach

        ¡MUY IMPORTANTE! Poner el @endforeach porque sino rompe la ejecución
    4.5 Las imágenes deben estar guardadas en storage/app/public/productos y en la columna de imagen en la tabla productos
        el enlace debe ser productos/producto.jpg (NO storage/app/public/ porque eso ya lo hace el enlace público).
    4.6 Crear el enlace público de las imágenes
        php artisan storage:link
        Esto crea un enlace que apunta mediante public/storage a /app/public
    4.7 Para crear las vistas de los productos de cada página hay que añadir un función en ProductoController con la consulta necesaria y agregar en web.php la ruta para cada vista y función.
    
    Si se produce algún error al poner nuevos estilos de Tailwind y no se ven:
        - npm run dev
        - npm run build
        - php artisan optimize:clear
        - php artisan serve

6. Poner una animación en el número de la cesta cada vez que se añade un producto
    6.1 Modifica el span de la cesta en tu header (partials/header.blade.php) donde tienes el icono de la cesta, añade un id al span para poder animarlo (id="contadorCesta")
    6.2 En la vista de Producto, añade la clase  class="add-to-cart-form" al form del botón de Añadir a la cesta
    6.3 En layouts/app.blade.php dentro de la etiqueta script añade:
        document.querySelectorAll('.add-to-cart-form').forEach(form => {
        form.addEventListener('submit', function(e) {
            e.preventDefault(); // evitar recarga
            const data = new FormData(this);
            const url = this.action;
            fetch(url, {
                method: 'POST',
                headers: {
                    'X-CSRF-TOKEN': data.get('_token'),
                    'Accept': 'application/json'
                },
                body: data
            })
            .then(response => response.json())
            .then(result => {
                if(result.success){
                    // Actualizar el contador
                    const contador = document.getElementById('contadorCesta');
                    contador.textContent = result.contador;

                    // Animación pop
                    contador.classList.add('animate-pop');
                    setTimeout(() => {
                        contador.classList.remove('animate-pop');
                    }, 300);
                }
            })
            .catch(err => console.error(err));
            });
        });
    6.4 Define la animación en Tailwind en el archivo resources/css/app.css
        @keyframes pop {
        0% { transform: scale(1); }
        50% { transform: scale(1.5); }
        100% { transform: scale(1); }
        }

        .animate-pop {
        animation: pop 0.3s ease-in-out;
        }
    6.5 Modifica el controlador de la cesta 
        public function add(Request $request)
        {
            $request->validate([
                'idProducto' => 'required|integer|exists:productos,idProducto'
            ]);

            $usuario = Auth::user();

            $item = Cesta::where('idUsuario', $usuario->idUsuario)
                ->where('idProducto', $request->idProducto)
                ->first();

            if($item){
                $item->cantidad += 1;
                $item->save();
            } else {
                Cesta::create([
                    'idProducto' => $request->idProducto,
                    'idUsuario' => $usuario->idUsuario,
                    'cantidad' => 1
                ]);
            }

            // Devolver contador actualizado
            $contador = Cesta::where('idUsuario', $usuario->idUsuario)->sum('cantidad');

            return response()->json([
                'success' => true,
                'contador' => $contador
            ]);
        }

7. integrar pasarela de pago Stripe en la vista de pedido
    7.1 Instala el SDK oficial de Stripe: composer require stripe/stripe-php
    7.2 Añade tus claves en .env:
        STRIPE_KEY=pk_test_xxx   # clave pública
        STRIPE_SECRET=sk_test_xxx # clave secreta
    7.3 Configura el servicio en config/services.php:
            'stripe' => [
            'key' => env('STRIPE_KEY'),
            'secret' => env('STRIPE_SECRET'),
        ],
    7.4 Crear la ruta para generar la sesión de pago en web.php:
        use App\Http\Controllers\PedidoController;

        Route::post('/pedido/stripe', [PedidoController::class, 'stripeCheckout'])->name('pedido.stripe');
    7.5 COnfigurar el controlador de PedidoController:
        use Stripe\Stripe;
        use Stripe\Checkout\Session as StripeSession;

        public function stripeCheckout(Request $request)
        {
            $usuario = Auth::user();
            $cesta = $usuario->cesta()->with('producto')->get();

            if($cesta->isEmpty()){
                return redirect()->route('pedido.checkout')->with('error','Tu cesta está vacía.');
            }

            $line_items = [];

            foreach($cesta as $item){
                $line_items[] = [
                    'price_data' => [
                        'currency' => 'eur',
                        'product_data' => [
                            'name' => $item->producto->nombreProducto,
                        ],
                        'unit_amount' => $item->producto->precio * 100, // en céntimos
                    ],
                    'quantity' => $item->cantidad,
                ];
            }

            // Envío
            $line_items[] = [
                'price_data' => [
                    'currency' => 'eur',
                    'product_data' => [
                        'name' => 'Envío estándar (3-5 días laborables)',
                    ],
                    'unit_amount' => 395, // 3,95 € en céntimos
                ],
                'quantity' => 1,
            ];

            Stripe::setApiKey(config('services.stripe.secret'));

            $session = StripeSession::create([
                'payment_method_types' => ['card'],
                'line_items' => $line_items,
                'mode' => 'payment',
                'success_url' => route('pedido.exito'),
                'cancel_url' => route('pedido.checkout'),
                'customer_email' => $usuario->correo,
            ]);

            return redirect($session->url);
        }
